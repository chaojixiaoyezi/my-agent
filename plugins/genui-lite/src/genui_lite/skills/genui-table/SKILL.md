# genui-table：数据表格与图表

本 Skill 随 genui-lite 插件安装；插件停用后它也随之消失。它只说明怎么用插件的两个工具，本身不授予任何权限。

## 什么时候用哪个工具

- `table`（只读）：用户想**在对话里看**数据——表格、排名、占比感、某列的条形图。结果直接包含 Markdown 表格、
  可选的文字条形图（█）和一句"共 N 行 M 列"摘要，把它们原样展示给用户即可，不要自己重排数据。
- `export`（会写文件，需要用户审批）：用户明确要**一个文件**——"导出成网页""生成 HTML 报告""发给同事看"。
  只在用户要文件时调用；只是想看看数据时用 `table`，不要顺手导出。

两个工具都可以带 `chart`（数值列名）。先不确定列名时，先用 `table` 不带 `chart` 看一眼列，再决定画哪一列。

## 数据格式

输入必须是工作区里的 UTF-8 JSON 文件，只支持两种形状：

```json
[{"月份": "1月", "销售额": 12800, "订单数": 64}, {"月份": "2月", "销售额": 15300, "订单数": 71}]
```

```json
{"columns": ["月份", "销售额", "订单数"], "rows": [["1月", 12800, 64], ["2月", 15300, 71]]}
```

- 每行的字段（或单元格数）必须一致；单元格只能是字符串、数字、布尔或 null，不能嵌套。
- 画图的列必须全部是非负数字；有文本、空值或负数时插件会明确报错——把报错原样告诉用户，不要改用别的列硬画。
- 数据在对话里而不在文件中时，先征得用户同意把它写成工作区 JSON 文件，再调用插件；不要编造数据。
- 行数超过设置 `max_rows`（默认 200）会截断显示并在摘要里注明；文件超过 `max_input_bytes`（默认 512 KiB）会被拒绝。

## 导出路径怎么选

- 输出必须以 `.html` 结尾，放在**当前工作区内**，默认放在数据文件旁边、同名改后缀，例如
  `data/sales.json` → `data/sales.html`；用户指定了路径就用用户的。
- 输出已存在时插件默认拒绝（`OUTPUT_EXISTS`）。先问用户是否覆盖，得到明确同意才带 `overwrite: true` 重试；
  否则换一个新文件名。
- **不要在工作区外写文件**：不要用 `..`、家目录、`/tmp` 或其它绝对路径绕出工作区；宿主写入范围拒绝时，
  告诉用户原因，不要换路径反复尝试。
- 生成的 HTML 是单文件：内联样式、内联 SVG 条形图，没有脚本和外部资源，可离线打开。导出成功后把返回的
  路径、字节数和行列数告诉用户。

## 常见错误

| code | 含义 | 怎么办 |
| --- | --- | --- |
| `INVALID_JSON` / `UNSUPPORTED_FORMAT` / `COLUMN_MISMATCH` | 数据不是上面两种形状 | 告诉用户哪里不对，经同意后修正数据 |
| `CHART_COLUMN_NOT_FOUND` / `CHART_COLUMN_NOT_NUMERIC` | 图表列不存在或不是纯数字 | 按返回的可用列重新选，或不画图 |
| `FILE_TOO_LARGE` | 超过 `max_input_bytes` | 请用户缩小数据或调整插件设置 |
| `OUTPUT_EXISTS` | 输出已存在 | 问用户是否覆盖 |
| `PATH_WRITE_SCOPE_BLOCKED` / `PATH_READ_SCOPE_BLOCKED` / `UNSAFE_PATH` | 越界或路径含链接 | 换到工作区内的普通路径 |
