# 同领域合并

学第二个同领域 agent 时（比如已经有短剧分场包，又学了一个短剧配音方法）：

1. 用 `skill_search` 找到已有的包，读它的 `CAPABILITY.md`。
2. 问用户：“并进已有的 <包名>（新增一个方向），还是单独成包？”这只决定做成哪种。
3. 并进去：
   - 用同一个 `plugin_id`，版本号升一级；
   - `CAPABILITY.md` 按方向分节（如“## 方向一：分场”“## 方向二：配音”），每节写清来源；
   - 新方向的文件放到自己的子目录（如 `methods/dubbing/`），LICENSE 和 PROVENANCE 按来源分开保留；
   - `keywords` 合并两边的领域词，`description` 改成覆盖两个方向。
4. 单独成包：换一个新的 `plugin_id`，按正常流程做。
5. 并错了：用户发 `/plugins#<包名> 退回`，宿主会先说明退到哪一版，再发回执最后那一行就回到合并前那一版。
