# 产品能力与边界

本页说明当前代码提供的功能，不把“有实现”当成所有环境均已验证。发布风险与未关闭问题以
[STATUS](../STATUS.md) 为准，后续开发见 [ROADMAP](ROADMAP.md)，验收方法见 [TESTS](../TESTS.md)。
旧部署现场、历史性能数据和单次成功记录不作为当前产品承诺。

## 使用入口

| 能力 | 当前行为 | 重要边界 |
|---|---|---|
| 终端助手 | TUI 提供会话、输入、流式回答、工具记录、思考折叠和历史分页 | 客户端与 Gateway 版本分别核对；短问候不证明长任务稳定 |
| 模型管理 | `/model` 配置服务商、协议、模型、上下文容量与请求头 | 密钥属于用户私有配置；保存配置不自动调用模型 |
| 模型作用域 | 当前会话独立选择，用户默认用于按规则继承的新会话 | 工作片冻结连接配置；子代理可继承或显式选择本 owner 可用模型 |
| 权限模式 | `/permissions` 管理 ask、auto、full-access | full-access 仅可信管理员；owner 隔离与专用人格确认仍有效 |
| 会话控制 | 支持插话、停止、恢复、目标模式和任务清单 | Todo 是软计划，不是机器质量验收；普通 final 不据此暗中续跑 |
| 子代理 | 创建、递归协作、进入子页面、插话、停止、结果通知 | 所有控制按结构化父子身份执行；终态和通知必须可恢复、可去重 |
| 文件工具 | 读取、写入、搜索、结构化补丁及大输出引用 | 文件存在性、权限和副作用事实不能用模型口述替代 |
| 命令与进程 | 批处理命令、交互 PTY、受管后台进程 | 三类句柄不同；进程启动不等于端口可达或业务正常 |
| 网络与扩展工具 | 网络请求、MCP 与技能按当前工具快照加载 | 外部环境、账号、通道和工具依赖需分别配置与验证 |

使用说明见 [README](../README.md)；TUI 设计见 [交互说明](design/TUI_DESIGN.md)，模型配置见
[模型管理](design/TUI_MODEL_PROFILES.md) 与 [会话模型选择](design/SESSION_MODEL_SELECTION.md)。

## 用户、会话与长期数据

- 每台机器使用一个 Gateway 服务多个用户和客户端，不按 TUI 数量创建额外 Gateway。
- 每个用户拥有自己的 canonical home。普通任务默认在家内工作，`tasks` 等目录用于整理建议，
  不形成“自己的另一个任务目录不能访问”的锁。外部目录仍受权限控制。
- 同一 owner/thread 只有一份 canonical transcript。展示分页、子代理通知和后台恢复不另造模型历史。
- 普通回合保留已提交历史的稳定前缀；真正摘要替换才走 Compact。主、子、孙代理各自使用同一套
  checkpoint 与 generation 协议，不共享彼此的正文或长期记忆。
- 长期记忆由所属用户的代理维护；普通记忆可自主更新，SOUL 修改需要用户确认。技能索引按需发现、
  正文显式读取；自学习默认关闭，学习候选不自动成为正式技能。

详细说明见 [家目录布局](architecture/MY_AGENT_HOME_LAYOUT.md)、[上下文](design/CONVERSATION_CONTEXT_DESIGN.md)、
[Gateway](design/GATEWAY_DESIGN.md) 和 [子代理运行协议](modules/subagent/SUBAGENT_RUNBOOK.md)。

## 遥测与完成语义

- Context 表示当前线程的请求上下文压力；累计 token、缓存读写、输出速率不是同一个指标。
- `compact N` 来自成功提交的压缩代数，不按屏幕内容多少或普通展示折叠推算。
- 模型不再请求工具时可以结束普通回合，但 `turn_end.reason` 不证明整个项目已完成。
- 工具失败、执行器退出、结果写回失败和投递失败必须分别记录，不能一概称为“模型配置错误”。
- 健康慢流不能因为耗时长被当成死亡；真正执行器退出仍需产生可追踪的终态并通知父级。
- 局域网服务需要从另一台机器访问验证；仅监听成功、旧构建成功或模型声称完成均不足以证明交付。

## 尚不能承诺的范围

无结果执行器退出、积压收口恢复公平性、连续大上下文核算、存量目标迁移和小时级慢模型交互仍有
开放问题或待复验组合，详见 STATUS。IM、桌面控制、跨平台与大规模并发按实际环境分别验收；
代码或协议入口存在，不代表所有外部环境都已经通过。
