## 复用和配置

复用原 ToolRegistry、TaskLink/RuntimeDB、SchedulerRepository、模型目录、私人签名交互、密文 TaskCredential、DeliveryService 与原权限/网络上界，没有第二套身份、任务或秘密账本。

新增部署开关：`im_model_cards_enabled=true`、`feishu_cloud_verify_sheet_writes_enabled=true`（capability 配置）；`query_zero_result_review_enabled=true`（agent 配置）。关闭前两项分别保留文字模型入口或省去写后核对，关闭后者只省新增软指导，查询事实继续如实记录。

富客户端候选增量改为累计净化后的完整行，模型/工具明确边界再释放后缀。单批未完成凭据键和值不能单独进公开事件；IM 仍用累计草稿，不改内部模型响应或工具参数。

## 凭据迁移边界

新凭据应使用 `request_credentials` 私人卡，模型/子代理只持 `credential_ref`，宿主按原任务/监控和准确 origin 使用。不要给任意脚本注入秘密后声称脚本不可读取，也不要在缺凭据时回落硬编码。

旧聊天/记忆/脚本/运行缓存可能已有明文；本期不盲改生产任务、历史数据库或脚本常量。迁移必须先按准确 owner 与路径做只读清单（只报类别/位置，不报值），给每个实际认证依赖换成原宿主 HTTP/来源凭据引用并读回验证，然后删除已确认冗余副本并轮换已在群公开的旧凭据。执行期间的旧任务不可静默换身份或密钥；需沿原更新/撤销与任务控制入口选择生效点。
