## 接手与停止语义

暂停 Goal 只停止目标自动续跑；中断当前回合才停止当前模型／工具执行链；
停止任务资源只处理明确归属的进程、终端和子代理。三者不能混同。
任何交接须附当前基线、dirty 文件、独占范围、已测／未测、真实 TUI／tmux、风险和下一动作。
不把个人信息、凭据、私有资料和绝对个人路径写入仓库。

## 收口条件

本地实现、focused tests、真实矩阵、严格 gate 与发布核对分别完成后才关闭 Goal。
指定版本／明确范围以外的100%迁移、自动融合和自动回滚上一版本，不在首期承诺内。
若被外部依赖阻塞，保留可验证进度和明确缺口，不把“暂时停止”写成成功完成。

建议下一步：一条线只读定位真实召回缺口，另一条线用冻结的显式选择用例对照，长任务线独立核验原子代理和交付证据。
