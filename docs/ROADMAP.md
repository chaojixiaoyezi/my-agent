## 优先修复

- **进度补丁误重置（已修、真实续做已验）**：只更新备注/元数据不再把 Todo 或覆盖目标重置为 pending；
  更正开关也不补造状态，新建默认和明确状态更新保留。旧数据不按文本倒推，模型换路效果另行验证。

- **等待子代理时追问的工具身份（已修、真实复验通过）**：真实消息编号被当成 run，读取和命令都被权威门拒绝。
  已在主入口同时回填真实 run/attempt，消息 request 保持不变；原会话恢复后 14 项测试通过，
  另一会话等待两名孩子时插话能实际执行命令，孩子仍继续；权限门不放宽。

- **用量异常收口与前后台去重（已修、真实增量验收通过）**：统一成功/错误/取消结算；source 不再形成重复收费边界，
  累计容器用代次区分重启。正常 TUI 中断与追加、多子代理 Goal 插话/后台整合/Compact 已对账；旧源账未篡改。
- **账号登录（已实现、真实账号授权待验）**：订阅登录与通用设备码 OAuth 参数、退出、刷新和取消。
  真实 TUI 与服务商账号权益分别验收，不把本地替身协议测试称为 Plus/Pro 账号通过。
- **慢模型失败分层**：本地工具语法编译 400、单槽排队首事件超时和多工具流不完整分别取证；
  每模型已增加显式额外排队预算，真实慢环境仍须复验；它不解决另外两类问题。
  后台 Goal 必须直接展示脱敏失败原因。健康流 45 分钟不中断不代表任务可用。

- **成功调用复读（观测链已修，慢模型长任务恢复未通过）**：重复门自身拒绝不再清空或挤掉原观测；
  新增固定间隔成功提醒、跨有界窗口计数与完整原始结果摘要；慢模型仍需真实验证是否换路。
  后台策展同端点前台让行、预算传递和超时取消已完成定向回归，外部应用缓存争用不在此保证范围。
  模型原回执保留计数与换路建议，文本读取失败说明能力边界。确定性长序列、真实工具和 TUI 分开验收，
  两个连续真实 TUI 任务正常收尾，但未触发循环门；原在用慢模型未重启，不把任务完成说成所有模型退化已解决。
  新慢模型任务已实测同一成功 Shell 命令 9 次，随后才承认文件不完整，完整产物验收未通过。
  恢复现场新增：受管进程无输出时重复 wait，uptime 变化使整包哈希持续变化；稳定进展与显示计时已分开并通过回放，
  不能因此强杀仍存活的下载、引入任务完成门或无限重试。另已补修 TUI 系统校时导致的假超时，真实注入复验通过。

## 下一轮验收

- 多用户、多 TUI、单 Gateway：不同模型、文件归属、记忆与技能调用、交叉并发。
- 连续任务：长调研、多子代理、插话、后续修改、模型切换、压缩和恢复。
- 慢模型：长首 token 等待、持续低速输出、断线重连；并行测试滚动、复制、输入和停止响应。
- 生命周期：子代理正常完成、失败、取消、执行器退出、结果写回失败、父级通知重投。
- 交付：代码实际运行、端口绑定与局域网可达；模型说已启动不等于验证通过。
- 需环境项：IM 渠道、真实桌面控制、企业规模存储和灾备按可用环境另列，不计为通过。

## 开发方式

每次按模块提交，定向回归先于真实 TUI；共享代码入口只由一个实施者修改。独立测试可并行，但不能为加速创建额外 Gateway。测试、开放问题和修复影响一起记录。
