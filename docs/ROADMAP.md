## 下一轮验收

- 多用户、多 TUI、单 Gateway：不同模型、文件归属、记忆与技能调用、交叉并发。
- 连续任务：长调研、多子代理、插话、后续修改、模型切换、压缩和恢复。
- 慢模型：长首 token 等待、持续低速输出、断线重连；并行测试滚动、复制、输入和停止响应。
- 生命周期：子代理正常完成、失败、取消、执行器退出、结果写回失败、父级通知重投。
- 交付：代码实际运行、端口绑定与局域网可达；模型说已启动不等于验证通过。
- 需环境项：IM 渠道、真实桌面控制、企业规模存储和灾备按可用环境另列，不计为通过。

## 开发方式

每次按模块提交，定向回归先于真实 TUI；共享代码入口只由一个实施者修改。独立测试可并行，但不能为加速创建额外 Gateway。测试、开放问题和修复影响一起记录。
