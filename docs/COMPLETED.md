# 已实现能力索引

本页列产品能力，不保存逐次测试流水；“已实现”不等于所有极限环境验收完成。

- 会话：持久历史、前后台接续、用户插话、会话独立模型选择。
- 代理：递归创建和控制、精确身份、生命周期收口、父级结果通知。
- 工具：文件与搜索、补丁、命令、PTY、网络、MCP、权限与输出归档。
- 记忆：用户隔离、摘要归档、检索、技能发现和按需正文读取。
- 界面：流式正文、折叠思考、工具展示、历史分页、完整详情、任务清单与子代理视角。
- 运维：单 Gateway、多用户、持久调度、健康诊断、受管后台进程和部署脚本。

当前仍有开放风险，见 [STATUS](../STATUS.md)。功能操作见 [CLI_REFERENCE](../CLI_REFERENCE.md)，设计入口见 [DESIGN_LEDGER](../DESIGN_LEDGER.md)。

## 紧凑状态与结果引用

解决问题：模型查询得到巨大界面快照，关键状态被裁剪，还被内部恢复路径引导到拒绝读取的循环。
现从同一授权快照生成紧凑状态和真实 read_order；内部摘要不作为结果，已存在终态报告可供无产物的任务读取。
大结果按原工具归档保存，模型摘要保持有效 JSON、原始路径与明确省略计数。查询不额外要求父级结束回合。
153 项相关定向回归通过；包含更新一条落后于独立子目标字段的旧 schema 顺序断言。
双真实 TUI 的完成后查询和读取已通过：会话不串其它窗口；主请求作为根时能查到真实孩子；
只读协作者没有写文件时，现有终态报告也进入可读索引。中长任务正常收尾，分工质量另评。

Context 下方新增本次逻辑模型轮、当轮工具数、最近缓存比例、当前代理会话累计消耗；宽屏补充输出速度与输入/输出分项。

## 软件不预选模型

解决问题：预填模型名、另一份启动模型投影和后台配置失效后的回退，容易误导当前模型身份。
模型协议、名称和端点默认留空；未配置适配器只允许进入设置，不发送模型请求。
状态工具只保留当前调用配置，后台整理记忆不因失效引用而改用启动模型。用户自己保存的选择不变。
定向回归与单 Gateway 双用户 TUI 已验证空配置菜单、明确失败以及显式选定模型的真实调用；
这不保证模型口头自报永远正确，实际模型仍须以请求配置和调用事实核对。本机在用会话未重启。

## Goal 续跑承诺与执行范围

解决问题：回合参数里残留 Goal 编号时，工具轮限交接仍可能承诺继续；系统持续执行规则又把独立后台目标交回当前回合。
续跑承诺现在重读精确 thread/task/goal 的持久状态，仅 active 且归属一致才有效；完成、暂停、删除、绑定冲突或读取失败均不承诺继续。
系统规则区分本轮 Goal 与普通子代理；每代理单目标规则已替代早期的多个命名目标并行执行方案。
生命周期状态与请求配置定向测试通过；这只证明上述确定性缺陷得到修正，不代表并行分工已验收。
新包真实 TUI 已完成单目标审查、目标展示、最终收尾与后续普通追问；后续消息没有重开已完成目标。
真实用例未触发工具轮限分支，该分支仍属于定向验证范围。
真实多目标 TUI 仍出现重复核验、重复派工，保留为开放问题，不以新增提示、目录锁或机器质量门代替修复。

## 每代理单目标与目标编辑

解决问题：多个并行目标归属混淆、子代理没有独立目标，以及用户无法直接纠正目标。
每个代理线程最多一个未结束 Goal；主子各自计费、续接、停止，prompt-only 派工不自动继承父目标，Todo 可选。
TUI 方向键选中目标后 Enter 编辑，Ctrl+S 保存、Ctrl+G 放弃；Esc 停止当前代理并暂停其目标，不保存草稿。
保存按内容版本比较，不被用量刷新干扰；后台修改或状态变化导致冲突时保留草稿，暂停编辑不恢复执行。
真实 TUI 验证父子创建、保存、放弃、停止及新要求被消费；同时修复父子邮箱串读与编辑快捷键冲突。
孙级、多次压缩与小时级慢模型组合仍须另验，详见 [持续目标](design/THREAD_GOAL_LIFECYCLE.md)。

## 父子并行与阶段诊断

已删除成功通知的全树终态屏障、创建子孙后的强制让出与相应废弃计数字段。
新结果逐项交给直属父级，忙父级复用安全点，空闲父级复用原调度车道；等待释放与迟到结果按结构化快照处理。
长等待提醒复用 runner 心跳，按首 token、流静默、工具、审批与退避区分；去重提醒不改状态，不自动强杀或重派。
定向验证与四路真实 TUI 已完成：先接入快结果、独立整合、低阈值提醒送达后原 attempt 自然完成。
测试阈值已恢复，孙级链路补验与分工质量、故障组合分别记录，见 [并行执行](design/SUBAGENT_PARALLEL_EXECUTION.md)。

## 子代理文件交接与工作目录

自然最终回复与结构化结果共用本 run 工具产物账本，父级不再因未收到模型 JSON 而拿到空文件清单。
投影保留精确身份、最新文件记录和读取诊断，排除其它 run、工具输出归档、删除及缺失记录；不代写文件。
多文件补丁把实际提交目标交给同一工具账本，移动/删除保留墓碑，部分失败不登记尚未提交目标。
删除内部输出重定位、交付映射和完成时自动复制。相对声明使用可信 cwd，绝对目标不变，声明不扩权。
缺少 cwd 时不猜宿主目录，也不据此剔除文件锁。现有权限、正式授权和恢复记录保留。
定向验证覆盖自然/结构化结果、深度一/二、记录替换、补丁部分提交及 no-follow；真实 TUI 已核对
孙级交接、同会话追加和补丁登记后的父级验证。尚存模型行为问题与覆盖边界见 STATUS。

## 派工说明去冲突

派工快照只保留各 run 的运行、终态与故障事实，删除“有孩子运行就等待”的嵌套动作建议。
协调者只加载自己的冻结角色与简短角色索引，删除全部外包、永久禁止接手和亲手重写下级成果等旧规则。
根与递归协调者共用自身分工、按需等待和无冲突整合的软说明，不增加权限、目录锁或机器质量门。
定向套件 312 项，308 项成功、4 项已有 xfail。单 Gateway 三路真实 TUI 均已结束：
独立工作时父级确实先写自己的模块；依赖任务在孩子交回后自动继续；追加任务有真实协调者及两名孙代理。
后者仍发生转交父级职责和重复状态查询，第一次分层需求也被扁平化，均作为模型行为偏差保留，不能称效率全面通过。

## 执行器退出与恢复公平性

解决问题：子代理执行器已经退出却继续显示运行中；收口失败积压时旧记录恢复不到。
真实执行区间在 exact attempt 下登记，异常退出复用正式结果与父级通知链；未知副作用保留封存，
不自动重跑。恢复事件按未消费身份分页轮转，扫描游标与消费回执分离。
定向回归覆盖进程退出、同宿主执行区间退出、慢执行存活、换代、未知工具、121 条跨页及回执去重。
真实 TUI 及故障注入状态见 TEST_CHECKLIST，不以定向通过冒充全面验收。
