# Live Lab：初衷和想法

## 初心

让项目有一个“像用户真的在用”的演练台。单元测试负责小零件，Live Lab 负责把入口、配置、产物和跨模块流程串起来看。

## 服务谁

- 给用户：关键能力不是只在测试里存在，而是能通过真实命令跑出可见结果。
- 给父会话：每次大改后能用 suite 判断链路是否仍然闭环。
- 给开发者和初学者：可以从输入 fixture、运行命令、输出产物学习系统怎样工作。

## 为什么这样设计

- `live_agent_lab.py` 让命令稳定，case 可以继续按套件拆分。
- runner/cases/constants 分开，避免所有演练逻辑挤在一个脚本里。
- 离线 replay 让 LOG 链路不用每次花真实 API 成本也能验证。
- summary 和 artifacts 让失败可复查，而不是只依赖终端肉眼看。

## 不做什么

- Live Lab 不替代 pytest；它补的是跨模块、端到端、可见产物。
- 第一版不要求每个 suite 都调用真实模型。
- 不把演练失败吞掉变成 PASS；失败应该留下 stage 和可读原因。
