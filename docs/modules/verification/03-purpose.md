# Verification：初衷

这个模块只解决一个问题：让 Agent 说“测过了”时，有一份机器可核对的真实执行事实。

它服务普通聊天和普通任务，但不接管任务。模型仍像 会话运行时 一样自行工作、测试和总结；运行时只告诉模型：
刚才执行了什么规范命令、退出码是什么、测的是局部还是全量、之后代码是否又被修改。

它不是业务验收器。网页好不好看、报告是否满足用户、数据是否正确等仍需任务本身的工具、测试和主模型判断。

模型表述层另有一条始终生效的软边界：只能把亲自观察到的范围说成已验证；本机、模拟器、替代环境、局部
入口或单一身份的成功不能外推到另一机器、真实用户、外部服务或完整端到端。不能观察目标边界时，应说明
已验证到哪里和剩余复核步骤。该提示不写 verification 数据库，也不参与宿主完成裁决。
