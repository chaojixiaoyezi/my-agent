# Memory：初衷和想法

## 初心

让系统能在长任务、跨天任务和中断恢复时找回真正可靠的事实，而不是靠一段越来越模糊的聊天摘要硬撑。

## 服务谁

- 给普通用户：不用反复解释“上次做到哪、哪些规则必须遵守”。
- 给父会话：恢复任务时能找到权威事实、最近状态、route 命中和归档证据。
- 给开发者和初学者：可以学到记忆系统不是一个文件，而是写入、索引、路由、归档和诊断的组合。

## 为什么这样设计

- JSONL 适合第一版保持简单、可读、可手工修复。
- LocalStore 负责搜索和统一索引，但不取代原始事实源。
- route index 让长期规则按触发词和权威路径读取，避免全量注入上下文。
- raw archive 和 snapshot 在压缩或恢复前留证据，防止摘要变成唯一事实来源。

## 不做什么

- 第一版不做复杂向量数据库或分布式记忆服务。
- 不把所有历史都自动塞进 prompt。
- 不在用户明确 `--no-save` 时偷偷写归档。
- 不把模型总结当作不可质疑的事实源。
