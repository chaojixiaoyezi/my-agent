# 持续目标的创建与续跑

状态：单代理单 Goal、可选子目标与 TUI 草稿编辑已实现；定向回归与真实 TUI 主流程已验证。下文列明尚未覆盖的组合，不作为所有长期场景的通过声明。

## 当前改造决策

本节替代下文历史多目标试验的产品方向，下文保留为旧数据兼容与失败证据。

- 一个代理对应一个 canonical agent thread，最多一个未结束 Goal（暂停、阻塞、预算受限也算未结束）。完成记录保留历史。
- 主代理、子代理、孙代理各自拥有 Goal；子代理不能把父级 thread/task 的目标当成自己的目标。
- 独立 CLI 命令沿用已绑定会话及其明确的任务编号解析 Goal，不为读取目标提前建立会话任务链接；缺少身份的普通会话和子代理不借用它的路径。
- prompt-only 派工默认是普通任务，显式附带持续目标才启用 Goal；子代理可自行使用原有 Todo，也可直接工作。
- Todo 是进度展示，不是验收合同，不强制填写或全部勾完。Goal 的完成只来自结构化更新，不读取“做完了”等正文来改状态。
- 第二个命名目标返回已有目标冲突，不再隐式创建独立任务或后台执行器。存量多目标不删除、不悄悄合并或重新激活。
- 用户在当前代理视角通过方向键选 Goal、Enter 打开编辑；编辑草稿与运行状态隔离，Ctrl+S/保存提交，Ctrl+G/放弃退出。Esc 保留停止当前代理的原语义。
- 保存保持 Goal/task/run 身份、历史、用量和暂停状态；按内容版本作并发比较，冲突保留草稿，不按统计刷新时间判断冲突。
- 运行中保存后通过既有引导队列在安全边界交给模型；不杀工具、不重复启动代理。权限沿用 owner 与代理树控制，不接受提示词伪造目标身份。

## 权威与默认行为

- 普通聊天不会自动建立 Goal。模型只有在用户或系统明确要求时才调用 `create_goal`；说“已建立”或写 Todo 不是创建事实。
- `get_goal/create_goal/update_goal` 默认进入首轮工具 schema；显式工具授权与用户配置的延迟目录仍有效。
- 模型最终回复只结束一次 turn。持久 Goal 的 `active/paused/blocked/complete` 与用量限制才控制目标生命周期。
- `update_goal(complete)` 只完成目标，不提前将运行任务或父任务注册表标为 done。当前回合、待处理消息和未结束子树仍由统一 finalization 安全收尾；显式 blocked 保留现有可恢复停止行为。
- active Goal 在当前 turn 正常结束后安排一个去重 wake；不检查工具次数，不要求 Todo 存在或保持开放。
- 工具轮限交接的续跑承诺也重读精确 Goal 的当前状态；旧 `thread_goal_id` 只用于定位。目标完成、暂停、删除、任务绑定冲突或读取失败时，不因编号还留在回合参数中而承诺自动继续。
- 未终态子代理由生命周期事件唤醒父级；等待期间不额外轮询模型。取消、暂停、审批、未知副作用、执行错误和预算受限不会因为 Goal active 被绕过。
- 普通模式没有新增自动续跑；不会按正文中的“继续”“完成”决定调度或状态。

## 存量数据与编辑边界

- 旧版曾允许同一会话多个命名目标；新写入已停止这种行为。现有记录不删除、不自动合并、不在启动时激活。
- 旧同任务冲突仍需用户通过目标编号显式恢复；保留原目标、预算、用量和迁移来源，存量活跃执行未收尾时不迁移。
- 主代理、子代理、孙代理各自使用自己的 thread/run 归属。父代理通过明确的 target_run_id 和已有直属授权读取或修改子目标，用户通过当前会话树授权操作。
- 编辑请求携带 expected_revision，目标正文或状态变化才推进版本；模型记账不制造编辑冲突。
- 模型请求会记录已看到的 Goal 版本；请求进行中用户修改目标后，旧模型不能把新要求直接标记完成。下一轮读取新目标后仍由模型判断。
- 主代理 Goal 使用已有安全边界 wake，子代理 Goal 在同一执行器/attempt 中开始新的逻辑对话轮；每轮单独保存历史，Compact 沿原会话继续，不另建调度器。
- 停止代理同时暂停它自己的未结束目标。编辑暂停目标不恢复运行，也不修改父目标或越过已有授权。
- Goal 修改依靠内容版本 CAS 防止重复保存，成功后进入本代理的持久 guidance 队列；不是预绑某一活动轮的用户插话回执。子代理读取自身 run/thread 邮箱，不得因 root task 归属读取父级邮箱。

## 验证要求

定向覆盖工具默认可见、普通模式不自动建目标、无工具/无 Todo 的续跑、主子目标隔离、完成/暂停/错误/审批/预算不续跑、同 attempt 跨轮与 Compact、编辑版本冲突和旧数据显式迁移。
最终通过真实 TUI 验证自然语言建立 Goal、主子目标和 Todo 展示、保存/放弃/停止以及后续消息；以 goal/task/wake/用量账本与可见结果交叉核对。

## 本轮验证与发现

- 真实 TUI：主代理与子代理独立建目标，普通子任务不自动继承父目标；子代理自己维护 Todo，完成后父代理接收结果并汇总。
- 真实 TUI：修改主目标后父子分别继续，子代理正常完成；修改子目标后它收到补充要求并实际更新产物。保存正文与目标编号、版本、guidance 消费记录核对一致。
- 真实 TUI：放弃草稿不写入；编辑中 Esc 停止当前子代理并将其 Goal 暂停，未保存文字不生效。旧版本再次保存被拒绝，草稿保留。
- 真实 TUI：子目标执行中出现一次工具历史压缩，未换 Goal/attempt；完整跨逻辑回合与强制 Compact 的组合另有确定性回归，不把单次真实压缩扩大成所有压缩路径已覆盖。
- 修复父子邮箱串读：子代理的 root task 只表达谱系，不能用于领取父代理 guidance。统一消费和待处理检测按自身 run/thread 解析。
- 修复目标编辑的提交契约：内容版本 CAS 提供幂等，定义变更写入持久 guidance；不伪造绑定到活动输入轮的回执，不放宽原回执校验。
- 修复模态键盘冲突：编辑时主聊天快捷键停止接管，换行、Ctrl+E、Ctrl+S 留在编辑器；明确展示 HTTP 版本冲突，窗口宽度不随提示文案跳变。
- 定向回归覆盖跨 owner/会话/兄弟拒绝、直属父子授权、暂停编辑不恢复、统计变化不冲突、旧模型版本不能完成新目标，以及同执行器多逻辑回合。
- 发布检查补齐独立 CLI 入口的目标身份解析；旧多目标测试改为升级前数据样本，继续验证历史记录隔离和后续插话，不让旧测试重新开放多个未结束目标。
- 尚未真实覆盖：孙代理多层编辑、小时级慢模型、IM 入口、存量多目标显式迁移；不以本轮 TUI 结果关闭这些组合。已有输入回执与旧后台交付预期失败项仍按原问题跟踪。
