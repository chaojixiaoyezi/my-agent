# Main Agent Runtime Gates

当前只保留真正动作边界上的门：

- 路径、URL、命令和危险目录。
- 工具 schema、副作用和审批绑定。
- 子代理启动健康、取消、接管和状态审计。
- 当前 run 产物证明和交付收口。
- compact/resume 的恢复事实。

不要把质量偏好、任务深度或模型行为猜测做成前置硬门。质量不足应进入返工提示、证据要求或收口验收。

`task_progress` 的证据检查是软提醒：模型把本地文件写成进度证据时，运行时会对照本轮工具事实提示“读失败”或“没有成功读取记录”的路径。它不阻断任务，只防止 `PATH_NOT_FOUND` 这类失败被静默写成结论依据。
