# 候选经验锚点精确索引

经验锚点保留原完整合同：四种状态、add动作、当前合法scope、lesson/HOT；按(last_observed_at,candidate_id)全局降序，每scope/type最多3、总12。规范HAMT唯一头内增加anchorroot分组索引和版本/构建进度；节点最大值与实际成员路径核验，最终行仍规范读取，不以索引授审核权。

所有原候选增量计划同步删除旧组/旧排序并加入新值；原配额、coordinator写门、原子头及发表后清理保持。读者合并各组最大值，最多读取最终12条正文，不将前128位置窗口当完整答案。没有第二候选账、线程或后台轮询。

旧HAMT头首次使用时每128条沿原锁/准入发表一片，片间释放锁；同次后台调用连续完成，直到version完整才交给模型。失败保留已发表进度，冷重启续办；片间新mutation仍同步维护索引。暂存正文/树路径只属于当前片。首次构建是O(N)，正常读写不再全读历史。原JSONL沿既有唯一写口首次迁入HAMT，保留其原一次完整转换能力；本片不声称原JSONL首次转换也已有恒定内存。

空账不为索引发表新头；坏节点、非法版本、成员/排序不符或准入失败都保留错误，不签空。显式完整历史读口保持不变。
