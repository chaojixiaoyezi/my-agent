# 父子并行与活动诊断

状态：代码已实现，定向和四路真实 TUI 主链验收完成；孙级真实链路与故障组合仍待验收。

## 解决问题

有用的独立工作不能被未完成的兄弟阻塞；已完成的结果应及时交给直属父级。
等待不等于失败，进程心跳也不等于模型或工具有进展。

## 执行与等待

- 创建是普通异步工具结果。主、子、孙继续相同模型/工具循环，不因创建自动结束工作片。
- 回执提供已启动身份和事件交付方式，不强制父级结束。模型根据真实依赖继续独立工作，
  没有合适工作时自然让出；不以“保持忙碌”为由反复查状态、制造文档或重复执行。
- 有孩子仍运行时，自然让出的 task-local 父级保存 exact direct-child wait marker，
  不标为 DONE；任一新结果可以解除等待，而不是要求所有兄弟结束。
- 新工作片若再次等待，只登记仍活跃孩子，已处理终态不重复触发；暂停、取消和未知副作用不绕过。
- 模型答复后、等待登记前刚到达的结果按“模型已见快照”识别，未读终态仍保留待交接；
  等待记录的释放为原子操作，两名孩子同时完成不能各自消费同一记录。
- 普通成功通知只保留已有可配置短合批窗口，期限取首条已持久通知，不随慢兄弟无限后延。
- 合批只确认本轮实际交付的信封；预算外、晚到或重复投递各走现有去重和恢复账。
- 父级忙时在安全边界接收，空闲时沿原执行车道唤醒；不能同时启动第二个父执行器。
- 主代理给子代理分工、子代理给孙代理分工使用相同纪律；不能靠解析任务正文猜依赖或另建目录锁。

## 活动诊断与控制边界

- 活动证据复用模型调用账、工具执行状态、runner session 和 exact attempt；不建影子任务状态库。
- 区分首 token 等待、流式输出、工具执行、权限等待和执行器已退出。
- 持续慢流、长首 token、无输出长工具不能仅凭经过几分钟就判失败。
- 阶段持续异常时给父级有界诊断和精确身份，去重通知；父级可查看、插话、停止或继续等待。
- 明确退出沿原退出恢复合同；副作用未知保留 UNKNOWN，不重复执行或自动派替身。
- 提醒不能构成新的机器完成验收、固定强杀期限或周期性无变化 LLM 轮询。

### 配置和持久化

配置统一在 `agent_py_agent/config/capability_config.yaml` 与 `CapabilityConfig`：

| 配置 | 默认 | 含义 |
|---|---|---|
| `subagent_activity_notices_enabled` | `true` | 开启阶段化提醒，使用原 runner 心跳，无新线程 |
| `subagent_first_token_notice_seconds` | `600` | 首 token 或供应商退避结束后长期没有事件 |
| `subagent_stream_idle_notice_seconds` | `180` | 已开始输出后静默，或模型/工具边界间没有活动 |
| `subagent_tool_wait_notice_seconds` | `900` | 工具长等待；有精确审批记录时标记等待审批 |

三个时间项的 `0` 表示关闭该阶段提醒，不是执行超时。供应商安排的退避时间不算静默。
实际 provider 超时、显式任务预算和用户停止仍按原协议处理，提醒不覆写这些边界。

诊断保存在 canonical run 的 `attributes.runtime_activity_diagnostic`，schema 为
`subagent-activity-diagnostic.v1`。`notice_key` 由 run、attempt、阶段和活动身份构成，
同一阶段没有新证据只提醒一次；活动恢复更新为 `progress_resumed`，不另开健康汇报模型轮。
旧进度快照不能抹掉独立诊断字段，旧 worker 不能给新 attempt 写诊断。
根父级走既有 observation/wake 原子对，递归父级读原直属快照和等待记录，不越级广播。
快照按当前 root 的索引选 ID、canonical 文件核对，不扫描用户全部历史；心跳时间不进入模型快照。

## 验收

先定向合同、替身与重放，再用单 Gateway 的多 TUI 真实任务。
覆盖快慢混合、两批独立结果、递归派工后本地工作、父级忙/闲、取消、重复/晚到结果、
重启恢复、慢流/长工具不误杀，以及插话不丢。核对事件消费、执行身份与真实工具结果，
不能用 Working 动画或模型口头承诺代替证据。

### 本轮证据边界

- 单 Gateway、同一已验证官方模型配置，四路真实 TUI 分别完成 Markdown 检查器、日志分析器、
  资源巡检工具和已有工具的三分钟采样；不由测试者补写业务代码或产物。
- 日志解析子代理先完成时，文档子代理仍运行，父级已读取解析结果并更新整合进度。
  资源巡检任务中，父级在孩子运行时编写自己的命令入口；完成后各路 Working 正常收起。
- 独立重跑产物现有测试：Markdown 检查器 49 项通过，日志解析器 4 项通过。
  这是基本可运行性证据，不等于完整功能与文档毫无缺陷。
- 短阈值补验记录真实 `tool_wait`、`failure_confirmed=false`、`automatic_action=none`，
  投递回执为 `handled`，同一执行代自然完成。短阈值故意增加通知，不能用它评价正常费用；
  测试完成后移除覆盖文件，发布默认值保持上表不变。
- 两路分层需求被模型扁平派工，没有真实孙级身份，因此递归部分仅计定向测试通过。
  另见模型重复实现孩子模块、文档字段不一致等行为，保留在 [当前问题](../../STATUS.md)，不靠硬性任务目录锁修补。
