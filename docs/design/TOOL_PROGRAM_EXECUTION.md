# 有限只读工具计划与长操作交回控制

状态：2026-10-14，本期S17–S20源码实施与隔离验收中，真实供应商速度收益尚未测量。

## 参考与取舍

沿原 `ToolRegistry`、`ToolExecutor`、`ToolCall` 与 `tooling/segment_planning`，保留一次模型多调用、连续只读并发段和写屏障。参考本机Codex源码 `tools/parallel.rs`、`tools/code_mode/delegate.rs`、`handlers/unified_exec/exec_command.rs`：内部调用继续原ToolRouter/运行身份/取消，长过程返回原句柄；没有照搬动态JS运行时、宿主函数注入或另建工具权限系统。原合同索引已在前期评估检查，本轮仅追读这些具体入口。

既有批量执行适合独立调用，不能在同一模型响应中可靠填入尚未返回的数据。最小新增入口是默认渐进加载的 `tool_program`：有限JSON数据计划，不执行Python/JS、不提供imports/eval、不注入shell桥。第一版只允许原策略解析为read_only的动作，写入、删除、主动发消息仍用原工具。这个限制不会把工具作者误声明只读变成可靠安全保证，工具自身仍须正确声明效果与执行门。

开关在原capability_config：`tool_program_enabled: true`。关闭后发现与执行均不可用；原多工具调用继续正常。不能从程序参数选择owner、actor、attempt、schema、审批模式或内部参数。

## 执行合同

- 本轮快照必须包含并允许底层工具；先由原tool_search加载，不借包装器调用隐藏/未授权工具。
- 内部ToolCall从原外层准确run/turn/attempt派生，使用原schema；外层ID和步内序号形成稳定子调用ID，并保留显式parent_call_id。
- 嵌套并发复用普通轮的线程上下文安装/恢复，真实runner只由宿主注入。每一条内部调用重新走原ToolExecutor的参数补全、模型可见性、ActionPolicy、插件收紧、路径/网络门、预算、运行权威、取消、输出归档及事件观察。没有直接handler调用。
- 只读资格是必要上界，不等于已获授权。需要审批的内部调用返回拒绝/待审批事实，不在程序内挂起或代批。
- 并发仅用原调度描述和连续段计划。原max_parallel_tool_calls及工作片上限同源，写效果不进入此程序。
- 原输出归档保持完整证据。机械引用只读取本次安全JSON投影，不从截断预览扫描对象，不把其中的文字升级为指令或权限。
- 每个调用的准确ID、结果、错误、时间和refs保留在calls；原owner最小审计记录内部调用，不能通过后续筛选隐藏失败。
- 参数和中间值均有预算：最多16步、32工具调用；输入64KiB、累计中间结果2MB、最终模型视图UTF-8 16,000字节。超过范围明确incomplete/truncated，不假报全量或重新执行已完成调用。

## 数据步骤

工具步骤有 `id/tool/arguments`，可用 `foreach` 遍历此前数组；`calls` 表达一个独立只读批次。引用只接受准确 `{"$ref":"step_id#/JSON/Pointer"}`，当前遍历项为 `item#`，不支持字符串插值或任意表达式。条件 `when:{value:引用,equals:值}` 只能决定是否尝试后续步骤，不能移除已经发生的失败。

数据步骤有 `id/data/project`。project支持确定字段相等筛选、按JSON路径去重、字段投影、展开数组、分组计数、offset/limit分页；coverage分别报告原数、展开数、筛选数、去重数、当前页范围与是否完整。不存在的路径报错，不默默丢行；空页不等于来源没有数据。return_step仅选择本次已产生的步骤。

工具结果提供ok/status/output/json、有限handler_details与证据refs；不用整个ActionDecision、沙箱根或归档内部对象充当业务数据。完整结果沿原归档保存，最终有界结果沿原live_prompt_output机制进入模型，防止已经整理的小结果再次只剩预览。真正大输出仍保留原归档引用，结果截断显式标记。

## 长操作

继续原 `run_command(run_in_background=true)`、受管process_session、完成事件与停止。模型说明明确预计几十秒以上的命令优先取句柄，禁止换编号重复启动或sleep轮询。process_session.wait默认最多30秒交回控制，原session仍运行时保留原句柄与wait_budget；`process_session_wait_slice_seconds: 0`只关闭工作片限制，协议上限600秒、取消和原权限不变。等待届满不是进程失败或可以重跑的证明。

IM状态显示继续原独立120秒心跳，不为维持显示新增模型请求。返回句柄不代表服务器就绪，退出码/监听/网络验证仍沿原工具结构事实；不能因改为后台绕过权限、网络、输出净化或取消树。
