- 只用合成凭据/canary/接收器与自有临时目录。Linux测试使用原 .2 字节码运行时，隔离测试根，不重启生产/default Gateway，不调用真实飞书或现场平台，不读/打印真实口令。

## 不能预设的结论

用户提供的助手报告是待核证据，未读取对应生产文件，不以“关键词命中”证明真实秘密。跨owner不可读不代表本owner明文安全；群空间共享可见内容不代表私人凭据授权可以共享。环境变量/只读文件一旦给任意脚本读，就不能继续宣称模型或该脚本不可获取其内容。

用户建议中的“读不到回落硬编码常量”不能作为安全迁移：缺失受管授权应停止认证请求并报可读错误。未知或已开工的生产监控不得因此自动重跑、停用或修改。
