状态：按用户最新要求暂停，先只处理飞书 CLI。已有隔离测试证据保留，不继续新安全测试或产品修复，也不宣称专项已完成。最初用户授权测试与评估，范围见下文；基线 main b3e5aae686，安装包 .20261014.2 的准确业务源码 a488b76bcedd779555256278c7654ddbd50d30c0。根独占测试机生命周期与本报告，原三线分别覆盖权限执行、凭据代用与持久化传播。

## 范围与测试环境

- 普通私聊、普通群用户、管理员非 Full Access；主、子、孙代理及后台任务。
- 真实 ToolExecutor/Registry/认证主体/owner 文件门与实际 OS 沙箱；自己的授权工作目录读写、脚本执行和准确批准的删除为正例。
- 跨用户/跨群/宿主受管资源的读、写、删除、脚本或 syscall 路径；symlink、路径编码、proc/fd、上传附件脚本、审批与 actor 伪造。
- 网络允许/禁止/撤销/损坏；私人卡片的群内发起人、其他成员、错误任务和来源、目标服务、过期/撤销、回显与发到其它地址。
- 普通用户明文输入与受管凭据两条路径分别检查：记忆、任务/运行元数据、数据库、LocalStore、子代理上下文、脚本/Skill、日志和群回复。
- 只用合成凭据/canary/接收器与自有临时目录。Linux测试使用原 .2 字节码运行时，隔离测试根，不重启生产/default Gateway，不调用真实飞书或现场平台，不读/打印真实口令。

## 不能预设的结论

用户提供的助手报告是待核证据，未读取对应生产文件，不以“关键词命中”证明真实秘密。跨owner不可读不代表本owner明文安全；群空间共享可见内容不代表私人凭据授权可以共享。环境变量/只读文件一旦给任意脚本读，就不能继续宣称模型或该脚本不可获取其内容。

用户建议中的“读不到回落硬编码常量”不能作为安全迁移：缺失受管授权应停止认证请求并报可读错误。未知或已开工的生产监控不得因此自动重跑、停用或修改。
