# 会话旧账维护的有界推进

状态：已实现并完成临时目录行为回归；尚未合入、安装或作为真实长期数据验收通过。

普通调度首拍及六小时维护不再同步枚举全部任务、线程、租约与归档。原 `conversation_ledgers` owner storage lane 负责推进初始归档、孤儿锁、任务链接自愈及既有归档退休；所有变更仍通过原协调写门，领域动作仍在原 JSON/claim 锁内重读。维护游标只定位，不授予退休或执行权。

续点保存在原 owner maintenance 状态的 lane cursor，分开记录规范会话根目录位置、根内阶段、目录 cookie 和线程内活动/历史任务位置。原生目录续点及 TaskHistory 的稳定物理位置避免每次重启从历史前缀重扫；每片最多 128 个物理候选与 25ms。首次旧数据初始化可以有一次性成本，后继不得重复全历史扫描。目录被删或替换时按目录身份重新开始；未知、忙锁或未完成片不能作为完整无义务证明。

初始归档继续保留策略七天、终态 claim 七天及结案十四天合同；claim 移动前保留取消证明的原核验。活动锁不移动；孤儿锁沿原年龄、试锁、身份和对应数据缺失复核回收。坏活动 TaskLink 保留原字节隔离，幽灵历史 ID 在原线程锁内再次检查链接缺失及 detached claim 非运行后才剔除。线程 updated_at 不因维护推进而变化。

显式维护 API 返回计数、coverage 与 continuation。小规模原行为继续可在一片完成，大历史调用方必须提交续点后继续；程序启动和一片完成都不代表全量数据验收。跨平台目录后端必须保原小规模路径，并分别验证冷重启续点和缓存淘汰后的进展，不能用无法完成当空表。

## 预算与验证边界

lane cursor 的版本为 `2`，包含规范根发现位置、根内退休/GC 阶段及内层续点；旧平面游标沿原解析边界重放，不借游标签发删除权。guidance 原退休 journal 的水位独立保留。目录身份变化重启对应定位，坏记录的整轮扫描结束不等于 coverage complete；未知保留 partial 并让其它根继续。

新GC的 `bytes` 是根据本片精确文件大小保守预扣的读取上界，包含原锁内重读、TaskHistory页/成员与ghost claim检查，不是物理释放。超剩余预算返回续点，单项或投影正文超过单片允许范围则 unknown，保留原数据且不解析该正文。初次旧线程迁移沿已有 initialize 原语，在原线程锁内发表完整历史后窗口化 JSON；后继只读已完成manifest，不重复全量迁移。首次升级成本仍需单独实测。

独立调度只请求既有 CLI owner maintenance 入口，到期、开关、partial续作、状态锁与准入均复用其合同，不再维护另一份进程六小时时钟。Gateway已有独立owner维护通道，`prepare_tick(include_orphan_supervision=False)` 不重复触发内联维护。
