# TUI 行为验收清单

本清单描述应验证的行为，不把旧截图和临时日志路径作为永久通过证据。每轮测试需另记版本、会话、步骤、真实结果、问题及影响。

| 分组 | 必验场景 | 通过标准 |
|---|---|---|
| 启动 | 80/120/140 列、窄屏、Gateway 未就绪与断开 | 布局不越界，连接状态真实，失败有原因 |
| 输入 | 中文、emoji、组合字符、多行、长粘贴、历史草稿 | 光标与文本一致，不半提交、不双发 |
| 流式 | 思考→工具→结果→新思考→正文，慢输出 | 顺序正确、颜色区分、输入不卡，结束后活动状态停止 |
| 正文 | Markdown、列表、表格、代码、差异、长最终报告 | 宽度正确，最终报告无需额外展开才可见 |
| 工具 | 成功、失败、拒绝、后台命令、长输出 | 展示真实结果，完整详情可恢复，不用 Done 掩盖失败 |
| 历史 | 上翻、回到底部、完整分页、resize、长会话 | 锚点稳定、未读提示可见，旧消息不丢 |
| 复制 | 应用拖选、右键、输入复制粘贴、远程 tmux、F6 | 中文范围正确、复制渠道结果真实，滚轮模式可恢复 |
| 插话 | 模型等待、工具执行、等待子代理、最终回复阶段 | 用户行、队列和消费状态一致，后续回复处理输入 |
| 子代理 | 多个运行/终态子代理、隐藏项选择、进出视角 | 初始任务与完整过程可见，选择项不隐形，快捷键作用于当前代理 |
| 进度 | Todo 四行/全部、多个进行中、主子代理 token、压缩 | 状态来源唯一，当前上下文与累计用量分清 |
| 模型 | 同用户两会话选不同模型、不同用户、子代理指定 | 切换隔离、显示实际型号，不泄露凭据 |
| 权限 | 主子代理请求、允许/拒绝、管理员 full-access | 结构化权限生效，前端不能越权 |
| 压缩 | 主子代理、手动/自动、切小模型、连续任务 | 动画状态真实、次数正确、历史和任务记忆可续接 |
| 生命周期 | 停止、退出、重连、恢复、重复/乱序事件 | 终态不回退、不重复执行、不假完成 |
| 性能 | 小时级慢模型、长历史与多子代理同时活动 | 界面仍可交互；耗时分模型等待与本地处理记录 |

已知未关闭问题见 [STATUS](../../STATUS.md)，测试方式见 [TESTS](../../TESTS.md)。
