# 管理员共享模型目录

## 目的与当前状态

同一 Gateway 下，管理员可以保存模型 A/B/C/D，显式开放给用户；用户各自选择会话模型。
已实现服务端配置、菜单及定向测试；真实 TUI 验收结果由本轮验收记录单列，不能用本文件代替。

## 权威与开关

- 私有 provider/model 继续只有 `config/model-profiles/<owner 身份摘要>.json` 一份。
- `config/shared-model-profiles.json` 是共享开关目录，只保存 `shared:<原模型 UUID>` 引用，不保存凭证。
- 新部署目录不存在，等同全部私有。每次在 `/model` 的“管理员共享模型”中确认才开放一个模型。
  这是逐模型显式配置开关，不新增会自动发布模型的全局 YAML 开关。
- 共享范围是同一 Gateway 已认证的用户；费用由被发布的模型账号承担，确认框会说明。
- 管理权限复用可信 owner 的 `is_permission_admin`，来源定位复用 canonical `local/main`，不接受客户端路径或 owner ID。

## 使用和隔离

1. 管理员新增模型，选择是否共享，默认不共享。
2. 用户在“选择已有模型（当前会话）”选择私有或已共享模型。会话持久记录只有模型编号。
3. “新会话默认模型”改变当前用户未来默认，不改变已有会话。主/子代理仍按工作片冻结配置。
4. 发布和撤销都不改变任何会话的选择。撤销后正在执行的请求不中断；下一调用明确失败，不能偷偷切换供应商。
5. 删除、禁用、撤销或目录损坏时，菜单明确标记不可用，仍允许手动改选可用的私有、共享或显式部署连接。软件没有预填模型，列表有共享项也不代表已选用。
6. 子代理可引用可用共享编号；名称重名需要编号，管理员同一私有模型的共享别名不重复消歧。
7. 主动连接测试复用已有网络入口，共享配置仅为单次内存快照；成功和异常出口都清洗 key 和自定义头值。

这不共享聊天、Memory、工作目录、管理员权限，也不把连接配置注入业务任务。私有配置被用户主动编辑时，
引用它的未来请求会使用新版本；已经执行的请求保留原快照。供应商间缓存命中不作保证。
