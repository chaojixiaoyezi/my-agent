# 文本依据核对

本文件属于 drama-text-a。与其他包同名的 review.md 没有继承或覆盖关系。

- `source_sha256` 是否来自本任务当前输入文件的原始字节；不能采用 `file_version`、示例摘要或重新序列化 JSON 后的摘要。
- 每个保留的原文段落是否被场次承接；未采用的段落是否明确省略并说明原因。
- 原文明确陈述、改编新增和仍未知的内容是否分开；`source_ids` 有效只证明引用存在，不证明它支持新增因果或人物背景。
- 每镜的 `source_ids` 是否只取本场实际依据，`adaptations` 和 `unresolved` 是否逐项说明新增和未知；三数组齐全或引用合法不证明没有漏标，仍须对照原文逐镜阅读。
- 场次中的冲突是否真正发生；不可只在梗概里说人物改变，实际场次却没有变化。
- 镜头是否引用真实场次；每镜起点、主要动作、终点是否能连起来。
- 可见人物是否属于当前场次；画外信息不能被误写为可见角色。
- 初始画面有没有提前包含终点才出现的道具或信息。
- 每个场次和每个镜头是否都有可计算的有限正数 `seconds`；逐场镜头合计是否等于场次声明，总镜头秒数是否与显式原文目标一致。没有目标与目标非法须分开，不能以缺省代替非法输入。脚本检查这些数值事实，动作对白是否真能完成仍需阅读判断。
- 结构检查只证明资料之间可对账。对白、节奏、人物动机和改编效果由独立阅读给出具体问题，不制造单一自评分。
