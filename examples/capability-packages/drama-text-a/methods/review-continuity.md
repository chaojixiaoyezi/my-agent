# 镜头接续与物件状态审阅

先读本包 `methods/review.md`。本分表参考上游视觉运动与资产审阅，只检查已有文本的接续；没有真实图像/视频观察就不判断像素、表演或成片连续性。

## 先看同一镜，再看相邻镜

对本次范围中的每镜，将 `start_state → action → end_state` 放在一起读。起点是否已出现结束后才获得的物件或信息；主要动作是否足以解释起终点的变化；一个普通镜头中是否藏了未说明的时空跳转。问题须引用具体字段，不能仅写“前后不一致”。

再沿叙事顺序，把上一镜终点、两镜之间已写明的转场和下一镜起点一起读。跟踪会被下一镜使用的事实即可，不要求每镜重写完整设定：

| 相关对象 | 对照的事实 |
| --- | --- |
| 人物 | 在场/离场、位置/朝向、手的占用、可见动作、已知信息和受伤/淋湿等连续状态 |
| 物件 | 同一个物件的身份、持有者、所在手/位置、开合/完好状态和内容物 |
| 空间与时间 | 出入口、相对位置、地点/时间/天气/光线是否经过明确变化 |

交付里写了 `prop_states` 时，先看原检查器的 `prop_state_discontinuity` 和 `prop_holder_*` 提示，再回读对应的正文。检查器只比较作者自己填的标签，不读正文。所以标签对得上不代表正文写对了，正文里的接续仍要逐镜读。

若变化缺少承载，先回读场次和原文查找已存在的解释；未找到时标为待修订或未知，不替作品补一段交接。持有者与所有者分开，人物不在当前可见角色中也不能无说明地执行画面动作。

## 允许有意的叙事省略

转场、蒙太奇、回忆、梦境、时间跳跃或刻意失向可以改变状态。检查作品是否已表达该选择、观众能否区分，以及它是否违背用户约束。不要把所有跳变都判错，也不要求把不相关的日常动作逐一拍出来。

场次边界同样需要检查：上一场留下的关键物件、人物认知或悬念，下一场是否接住；场次更名或编号转换不自动证明内容连续。

## 给作者最小修订范围

每项问题写清三处：上一终点、现有过渡（或缺失位置）、下一起点。说明影响的是身份、持物、空间还是知情时机，并列出修订时需要保住的来源事实和有效镜头。

作者可以调整起点、动作、终点或明确创作转场，由实际依据决定；审者不以“加一个交还动作”作为通用答案。修订后重读改动镜及前后接缝，再按需要重跑结构检查。

秒数相加正确只证明数值一致。若动作与对白难以在当前时长完成，指出具体被挤掉的动作或信息；不使用固定的“每秒几个动作”或统一镜长硬阈值。
