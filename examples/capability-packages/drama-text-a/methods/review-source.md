# 原文事实与改编依据审阅

先读本包 `methods/review.md`。本分表参考上游原著分析与故事审阅，映射到本包当前原文/场次/镜头格式；不要求建立上游章节索引或第二份事实库。

## 从下游陈述回到原文

按本次声明范围逐镜读 `action`、`start_state`、`end_state` 及场次摘要，找出会改变人物关系、因果、知情范围、所有权、数量、时间或位置的具体陈述，再回读该镜声明的 `source_ids`。需要上下文时继续读相关原文；编号存在不证明支持关系成立。

对每项陈述区分：

- 原文明说：指出相应段落和必要短引文。
- 可以作为改编新增：核对是否已写进该镜 `adaptations`，是否改变用户明确要求保留的事实；合理或常见不是原文证据。
- 仍无法确定：明确标未知，核对 `unresolved`，不要补成肯定的背景或关系。

已有 `adaptations` 或 `unresolved` 也要看其内容是否覆盖当前疑点；数组不为空不是所有新增均已说明的证明。明确允许的创作取舍与未声明的来源事实改写分开反馈。

## 容易串错的关系

- 物件的当前持有者、接收者和所有者是否被混同；将要交给某人不等于本来属于某人。
- 说话者、被指代者、行动者是否被相邻人物替换；不能仅凭相似称谓合并人物。
- 角色知道的信息是否已在该时刻获得；后续揭示不能提前变成角色当前认知。
- 背景、时间、状态或细节是否由“画面需要”补出，却被写成原文明说。
- 省略或合并是否保住因果桥梁；镜头列了某段编号，却未承载它的关键事实时不能仅称“已覆盖”。

这些是阅读方向，不是触发词或自动判错规则。原文存在明确解释时保留它；不要为满足清单虚构矛盾。

## 场次和故事是否兑现

把场次开始时的处境与结束时的变化相对照：谁采取了什么行动，遇到什么阻力，信息、关系或结果因此怎样改变。若某变化只存在于梗概、计划或子代理总结，而实际场次没有承载，指出两处材料的差异。

重大选择、时间压力或代价只在作品自己强调或用户明确要求时核对，不给所有故事强加同一种冲突公式。对白问题落到准确交流及其未改变的事实，不能只贴“生硬”或“模板感”标签。

## 留下能复核的问题

按模板给出“原文位置及事实 → 下游位置及冲突 → 应恢复结果 → 保持项”。例如应恢复正确关系或如实标注新增，不替作者编一个原文没有的交接事件。原文未交代时保留未知，不将审者推测反过来写进源材料。
