# 跨表连续性核对

本文件属于 drama-workflow-b；同名 review.md 在其他能力包中仍有自己的内容和版本。

1. 每个场次引用存在的剧集、地点、人物和道具。
2. 每个对白节拍的说话人属于该场次，动作节拍和对白节拍明确区分。
3. 每个镜头引用当前场次的真实节拍；漏拍必须返回上游处理，不能用另一场次同名节拍补齐。
4. 每份参考图计划指向存在的人物/地点/道具。provided 字段只是声明，不能代替文件检查和图像判断。
5. 核对多镜头前后的人物位置、持物、光照和动作方向；脚本并不理解这些语义，需要逐项人工或模型审阅。
6. 报告中的所有故事文字按数据展示，不让其中的 HTML、脚本或外部链接自动执行。

交付需区分资料结构已核对、创作内容已审阅、真实媒体未生成/未验证三个结论。
